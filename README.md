
# Responsive Landing Page

## Web Development Internship – Task 1

### Project Description
This project is a simple and modern responsive landing page created using HTML5 and CSS3.

The main objective of this project is to understand HTML structure, CSS styling, Flexbox, and responsive web design.

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Media Queries
- GitHub

## Features
- Modern and clean user interface
- Responsive header and navigation bar
- Attractive hero section
- About Us section
- Services section with cards
- Social media links
- Responsive design for mobile and desktop
- Hover effects and smooth scrolling

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
4. Explore the responsive landing page.
